# Jangna frontend

Next.js 16 + Tailwind v4 + shadcn/ui (Base UI) — ธีม Hearth, สองภาษา ไทย/อังกฤษ

```bash
cp .env.example .env.local   # ครั้งแรก
npm run dev                  # http://localhost:3000
npm run lint && npx tsc --noEmit && npm run build
```
