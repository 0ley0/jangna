# Payroll — engine, รอบจ่าย, กฎหมาย

## Engine (`backend/src/Jangna.Payroll.Engine`)
`PayrollCalculator.Calculate(PayInput, LegalRules) → PayResult` — pure, เรียกซ้ำได้ผลเดิม

| ประเภท | วิธีคิด |
|---|---|
| **Monthly** | เต็มเดือน = เงินเดือน, ไม่เต็มเดือน = เงินเดือน/30 × วัน; หักขาด/ลาไม่รับค่าจ้าง = เงินเดือน/30 ต่อวัน; ชม. = /30/8 |
| **Daily / Hourly** | จ่ายตามชั่วโมงเวลาปกติที่ทำจริง (สูงสุด 8 ชม./วัน), ได้ค่าจ้างวันหยุดนักขัตฤกษ์ที่ไม่ได้มาทำ + ลาได้ค่าจ้าง |
| **Piece** | ผลงาน × อัตรา × ตัวคูณ, วันหยุดนักขัตฤกษ์/ลาได้ค่าจ้าง ใช้ base rate ถ้าไม่มีใช้ค่าแรงขั้นต่ำ (มี warning) |
| OT วันทำงาน | 1.5 เท่า (ต่อชิ้น: ชิ้นช่วง OT × 1.5) |
| ทำงานวันหยุด | รายเดือน **เพิ่ม** 1 เท่า (เงินเดือนรวมวันหยุดแล้ว) / รายวัน-ชม.-ชิ้น 2 เท่า |
| OT วันหยุด | 3 เท่า |
| เติมค่าแรงขั้นต่ำ | Daily/Hourly/Piece: เวลาปกติของวันนั้นต่ำกว่า ขั้นต่ำ × ชม./8 → เติม (OT ไม่นับ) |
| ประกันสังคม | 5%, ฐาน clamp 1,650–เพดาน, ปัดเป็นบาท (≥ .50 ขึ้น); หลายรอบในเดือน → คิดทั้งเดือนแล้วหักส่วนที่รอบก่อนหักไปแล้ว (`MonthToDate`) |
| ภาษี ภ.ง.ด.1 | สะสม: ประมาณทั้งปี = YTD + รอบนี้ × รอบที่เหลือ → หักค่าใช้จ่าย 50% (≤100k), ส่วนตัว 60k, สปส., ลดหย่อนอื่น → อัตราก้าวหน้า → (ภาษีทั้งปี − หักไปแล้ว) / รอบที่เหลือ |
| ฟรีแลนซ์ | ไม่เข้า สปส., หัก 3% (ภ.ง.ด.3) ถ้ายอด ≥ 1,000 |
| เงินเบิก | หักได้ไม่เกินยอดคงเหลือหลัง สปส./ภาษี ส่วนเกินยกไปรอบหน้า (warning) |

ทุกอย่างผิดปกติ → `Warnings` (ไม่ throw) ยกเว้นชั่วโมงติดลบ และ rule set ไม่มีภาษี
`Warnings` เป็น `LocalizedText(Th, En)` — engine สร้างทั้งสองภาษา, frontend เลือกด้วย `t(w.th, w.en)`

**รหัสรายการ** (`LineCodes`): SALARY, UNPAID_ABSENCE, DAILY_WAGE, HOURLY_WAGE, PIECE, PIECE_OT, PIECE_HOLIDAY, PIECE_HOLIDAY_OT,
OT, HOLIDAY_WORK, HOLIDAY_OT, PUBLIC_HOLIDAY, PAID_LEAVE, MIN_WAGE_TOPUP, SSO, WHT, ADVANCE
→ แปลเป็นอังกฤษจากรหัสนี้ที่ `payLineLabels` (`frontend/src/lib/types.ts`) **และ** `Exports/PayLineLabels.cs` (สลิป PDF) — เพิ่มรหัสใหม่ต้องเพิ่มทั้งสองที่

## รอบจ่าย (`backend/src/Jangna.Api/PayRuns/PayRunService.cs`)
1. **Create**: ช่วงต้องอยู่ในเดือนเดียว, ห้ามทับรอบอื่น, ห้ามสร้างก่อนรอบที่ lock แล้ว → resolve rule set ณ วันสิ้นรอบ → snapshot → คำนวณ
2. **ประกอบ input ต่อคน**: work_days ในช่วง + วันหยุดร้านที่ยังไม่มีบันทึก (เป็น PublicHoliday), piece work, ค่าแรงขั้นต่ำของสาขา,
   YTD = ยอดยกมา + รอบที่ lock ในปีเดียวกัน, MTD = รอบที่ lock ในเดือนเดียวกัน, เงินเบิกค้าง, รอบที่เหลือในปี
3. **คนที่อยู่ในรอบ**: Active ทุกคน + คนที่ไม่ active แต่มีข้อมูลในช่วง; ไม่มีรายการและไม่มีเงินเบิก → ไม่ใส่
4. **Recalculate**: เฉพาะ Draft
5. **Lock** (Owner): คำนวณใหม่ก่อน → ถ้าผลต่างจาก draft ล่าสุด **ไม่ lock** (409) แต่บันทึก draft ใหม่ให้ตรวจ
6. หลัง lock: แก้ work_days / piece work / วันหยุด ในช่วงนั้นไม่ได้ (409), ยอดยกมาของปีนั้นแก้ไม่ได้
7. warnings เพิ่มจาก service: ไม่มีสาขา (ไม่รู้ขั้นต่ำ), ไม่มียอดยกมาตอนเริ่มกลางปี

| เอกสาร | เลือกรอบจาก | ใครอยู่ในไฟล์ | ไฟล์ |
|---|---|---|---|
| สปส.1-10 | งวดค่าจ้าง (`PeriodStart`) ในเดือน | ลูกจ้าง (ไม่ใช่ฟรีแลนซ์) ที่มีค่าจ้าง สปส. > 0 | `SsoFile` — fixed-width 135 ตัว/แถว, TIS-620, CRLF |
| ภ.ง.ด.1 | วันจ่าย (`PayDate`) ในเดือน | ลูกจ้างที่ถูกหักภาษี > 0, 1 แถวต่อ 1 การจ่าย | `Pnd1File` — คั่นด้วย `\|`, UTF-8, CRLF, ชื่อไฟล์ `PND1_{เลขผู้เสียภาษี}_{สาขา}_{ปีพ.ศ.}_{เดือน}_00_00.txt` |
| สลิป PDF | รอบเดียว (ทุกคน หรือคนเดียว) | ทุกคนในรอบ | `PayslipPdf` — A5 คนละหน้า, ภาษาตาม `employee.language` (my → อังกฤษ) |

ข้อมูลที่ต้องมี: ร้าน = เลขผู้เสียภาษี 13 หลัก, สาขา 6 หลัก, เลขบัญชีนายจ้าง สปส. 10 หลัก (`/app/settings`)
พนักงาน = คำนำหน้า, เลขบัตรประชาชน (ตรวจ check digit), อำเภอ/จังหวัด/รหัสไปรษณีย์ (ภ.ง.ด.1 บังคับ)

**ภ.ง.ด.1** ทำตามเอกสารทางการ "รูปแบบข้อมูล (FORMAT กลาง) ภ.ง.ด.1 ภ.ง.ด.1ก และ ภ.ง.ด.1ก พิเศษ" Version 2.0 (16/06/2568)
— rd.go.th/63724.html: header 22 ช่อง, detail 26 ช่อง, ตัวเลข `0.00`, วันที่ ววดดปปปป (พ.ศ.), ห้ามอักขระ `* + / \ ! $ % # & @ , ' "` (`/` ในบ้านเลขที่ → `-`)
มี RD User ID → FORM_FLAG 2 (อินเทอร์เน็ต) + TRANS_AMT = ภาษี, ไม่มี → 1 (สื่อ/ฝากไฟล์) · TAX_RATE = 0.00 (อัตราก้าวหน้า) · INC_TYPE 1 = 40(1), PAY_CON 1 = หัก ณ ที่จ่าย

**สปส.1-10 — สมมติฐานที่ยังต้องทดสอบอัปโหลดจริง** (ความยาวแต่ละช่องมาจากบทความ ไม่ใช่เอกสาร สปส. ทางการ):
1. ตัวเลขเป็นสตางค์ไม่มีจุด ชิดขวาเติม 0; อัตรา 5% = `0500`
2. ข้อความชิดซ้ายเติมช่องว่าง, ตัดเมื่อยาวเกิน; ปีเป็น พ.ศ. 2 หลัก (วันที่ชำระ ddMMyy, งวด MMyy)
3. ค่าจ้างที่แจ้ง = ค่าจ้างทั้งเดือนตัดตามฐาน 1,650–เพดาน ให้ตรงกับเงินสมทบที่คิด
4. รหัสคำนำหน้า 003 นาย / 004 นางสาว / 005 นาง; เลขประกันสังคม = เลขบัตรประชาชน
5. ไฟล์ TIS-620 (windows-874)

**วันจ่าย** (`PayRun.PayDate`): ไม่ระบุ = วันสิ้นรอบ, แก้ได้เฉพาะรอบร่าง, ต้องไม่ก่อนวันเริ่มรอบ ไม่เกิน 31 วันหลังสิ้นรอบ และอยู่ปีเดียวกับรอบ
(ยอดสะสมภาษีคิดตามปีของรอบ — จ่ายข้ามปีจึงยังไม่รองรับ)

`LegalDataSeeder` **sync rule sets จากโค้ดทุกครั้งที่เริ่มระบบ** (จับคู่ด้วย EffectiveFrom) — แก้กฎหมายที่โค้ดแล้ว restart

### ข้อสงสัยใน draft ค่าแรงขั้นต่ำ
- บทความระบุ "ประจวบคีรีขันธ์" ซ้ำ 2 ระดับ (352 และ 357) — ตีความว่าระดับ 357 คือปราจีนบุรี (TH-25) เพราะนับครบ 77 พอดี
- วันที่มีผลไม่ชัด (อ้าง 1 ก.ค. 2568) — ต้องเช็กว่ามีประกาศใหม่ปี 2569 ไหม
- ยังไม่รวมอัตราตามประเภทกิจการ (โรงแรม/สถานบริการ 400 ทั่วประเทศ)

### สมมติฐานที่ต้องให้ทนายยืนยัน
1. สปส. นับค่า OT เป็นค่าจ้าง
2. ลูกจ้างต่อชิ้นได้ค่าจ้างวันหยุดนักขัตฤกษ์ตามค่าจ้างรายวันพื้นฐาน (ไม่มี → ค่าแรงขั้นต่ำ)
3. ค่าแรงขั้นต่ำคิดตามสัดส่วนชั่วโมงเวลาปกติ (ครึ่งวัน = ขั้นต่ำครึ่งวัน)
4. คนช่วงเซล = ลูกจ้างหรือฟรีแลนซ์ (ถ้าทำในร้าน ตามเวลาร้าน มีแนวโน้มเป็นลูกจ้าง)
5. การหักค่าจ้างทำได้จำกัด → **ห้ามหักค่าแพ็คผิดอัตโนมัติ** (บันทึกอย่างเดียว)
6. ลดหย่อนภาษีอื่นๆ (คู่สมรส บุตร ฯลฯ) ยังเป็นยอดรวมที่ต้องกรอกเอง (`AdditionalTaxAllowances`)

## ตัวเลขอ้างอิงที่ใช้ในเทสต์ (คิดมือแล้ว)

- เงินเดือน 50,000, รอบที่เหลือ 12 → ภาษีทั้งปี 20,450 → หัก 1,704.17/เดือน
- เงินเดือน 50,000 เริ่ม ต.ค. + ยอดยกมา 450,000 → หัก 6,816.67
- คนแพ็ค กทม. 100 กล่อง + 50 กล่อง × 5 บาท → 900 (เติมขั้นต่ำ 150), สปส. 83 (ฐานขั้นต่ำ 1,650)
