# Product

SaaS ลงเวลา + เงินเดือน ผ่าน LINE สำหรับ SME ไทยที่จ้างพนักงานรายวัน/รายชั่วโมง/ต่อชิ้น

- **กลุ่มแรก:** ร้านค้าออนไลน์ที่จ้างพนักงานแพ็คสินค้า (ค่าแพ็คต่อกล่อง/ชิ้น + รายวัน, คนช่วงเซล 9.9–12.12)
- **กลุ่มถัดไป:** ร้านอาหาร (กะ, service charge/ทิป, หลายสาขา)
- **จุดขาย:** "แพ็ค = ลงงาน = เงินเดือน" ในระบบเดียว ผ่าน LINE — คู่แข่ง HR ทั่วไปไม่ได้เจาะคนแพ็ค
- **โปรเจกต์พี่น้อง:** Ruam Talad (`../ruam-talad`, รวมสต็อก/ออเดอร์ Shopee/TikTok) → ส่งออเดอร์มาให้ Pack module ผ่าน API/webhook
  แต่ Jangna ต้องใช้งานเดี่ยวได้

## ชื่อและแบรนด์
- ชื่อ **Jangna (จ้างนะ)** — เลือกแทน "Jangter" เพราะ jangter.com ถูกจดแล้ว
- ตัวอังกฤษ "Jangna" มักอ่านเป็น "จัง-นะ" → โลโก้ใช้ภาษาไทยเป็นหลักเสมอ + จด `จ้างนะ.com` / `จ้างนะ.ไทย` redirect
- Tagline (ร่าง): "จ้างนะ จ้างง่าย จ่ายถูก" / "แพ็คปุ๊บ นับปั๊บ จ้างนะจ่ายให้"
- Namespace C#: `Jangna.*`

## ราคา (ร่าง)
| แพ็กเกจ | เงื่อนไข | ราคา/เดือน |
|---|---|---|
| Free | ≤ 5 คน, ≤ 300 ออเดอร์แพ็ค | 0 |
| Shop | 1 สาขา ≤ 25 คน / ≤ 3,000 ออเดอร์ | 390 บาท |
| Warehouse | Pack module เต็ม (สแกน + วิดีโอ + ค่าแพ็คต่อชิ้น) | 790–1,490 บาท |
| ลูกค้า Ruam Talad | ใช้คู่กัน | ลด 20–30% |

คิดต่อสาขา ไม่คิดต่อหัว — ร้านอาหาร/คนแพ็ค turnover สูง เจ้าของไม่ชอบจ่ายต่อหัว

## คู่แข่ง (ต.ค. 2026)
- **HumanSoft** — HR ทั่วไป SME, เริ่ม 590 บาท/เดือน (10 คน), ลงเวลา 14 แบบ, มีภาษาพม่า, export สปส./ภ.ง.ด.1 → คู่แข่งหลัก
- **SMEMOVE** — บัญชี + เงินเดือน, Pro 699 บาท/เดือน
- **Bplus HRM Small** — โปรแกรมติดตั้งเครื่อง 7,500 บาท จำกัด 50 คน
- **PackStamp / Cam Booth** — อัดวิดีโอแพ็คอย่างเดียว ไม่ผูกค่าแรง
- Fulfillment (i-Sabuy ฯลฯ) ~10 บาท/ออเดอร์ → ใช้เป็นตัวเทียบต้นทุนแพ็คต่อออเดอร์ให้ลูกค้า

## ความเสี่ยงหลัก
- คำนวณเงินเดือนผิด = ลูกค้าเลิกใช้ → engine ต้อง test หนัก + มีหน้าตรวจก่อนปิดรอบ
- HumanSoft อาจทำฟีเจอร์ร้านอาหาร/คนแพ็คตาม → จุดต่างต้องลึกกว่า (Pack module + Ruam Talad)
- ร้านปิดตัวบ่อย → churn สูง
